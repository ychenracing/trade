## 五、必须澄清的边界（重要）

`daily_signal.py` 是**逐标的独立信号脚本**，只输出每只票的 BUY/HOLD/SELL，**不管理组合仓位、也不做回撤熔断**。因此：

- ✅ **信号层参数**（海龟 10/70、止损 2ATR、12 单位、均线 20/60）已与约束版完全一致；
- ⚠️ **「单票≤60% + 19% 熔断」是组合执行层风控**，不在信号脚本里。现已作为纪律写进定时任务 prompt 提醒你，但**不会自动执行**。
- 若要让定时任务自动卡这条线，需额外做一个**组合监督脚本**（读每日信号日志 + 你实际持仓，判断单票是否超 60%、是否触 -19% 需减仓/清仓），再挂到定时任务——这不是改 `daily_signal.py` 能解决的。
