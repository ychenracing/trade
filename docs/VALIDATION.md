# 验证结果、证据身份与适用范围

## 如何使用验证证据

工程回归、来源绑定的正式接受、研究对照与被拒候选是不同证据。当前产品文档展示现行配置、正式基线及其适用限制。维护源码与文字不会使已有经济结果自动成为当前提交的新回测；每份结果须按自己的源码、数据、配置、窗口和场景身份解释。

收益率 `total_return` 与财富倍数不同，财富倍数为 `1 + total_return`。最大回撤以负数报告。实际成交记录与日期／股票／方向桶分别统计，后者不是券商订单数；各袖套独立成交、双边分别承担费用，不能虚构跨袖套净额。

## 正式发布与诊断边界

正式 CLI 默认候选标识为 `native-default`，直接使用默认策略配置。财富比较使用固定 incumbent，相同场景 ID、类型与有序股票池配对；原始参考保留独立诊断。两份参考均按完整内容核验，缺少或替换参考即失败关闭。

新候选不得使用历史 release waiver 或首基线选项绕行。显式历史候选标识只支持诊断选择，不能通过正式 CLI 重新发布旧例外。历史工件和其来源绑定发布评价保留原接受依据；它们不证明当前默认策略已原生联合达标。

当前主池优先合同要求全部 958 场景回撤幅度不超过 18%，17 股主池含本金财富至少保留固定 incumbent 的 99%。五个场景族分别要求配对财富比率最低值至少 0.65、P10 至少 0.85、中位数至少 0.95。成交桶、换手、风险动作以及旧前缀、邻接、最差收益、add-one、相对回撤规则均完整保留为诊断，不独立否决。真实费用、资金、ADV、涨跌停、T+1、整手和因果约束继续生效。这明确允许最差子池损失 35% 的基准财富、P10 损失 15%、中位数损失 5%；不代表未来安全性。

有效规则是按用户明确授权一次性修订并冻结的 `artifacts/diagnostics/no_waiver/production-primary/contract.json`。并发续作产生的另一份 `production-pool-contract.json` 已标为被替代，不用于晋级。原始合同及其结果保持独立，每次新验收保存 `original_contract_assessment`；新合同通过不代表旧目标完成。通过时 `native_joint_acceptance` 记录两份参考身份、当前合同、原合同是否通过及 `waivers_used=false`；拒绝时保留各项失败。所有账户风险历史、实际成交及输入完整性要求继续适用。

使用 ID、family、ID 文件或 shard 筛选的压力任务都是诊断，只能写独立检查点与诊断 JSON，不能更新 canonical 工件。发布前 prefix 与 universe 的共同场景须逐条一致。读取当前正式基线时仍重算记录、门禁、发布评估与来源绑定；内部一致性不是数字签名，也不等于重新认证全部外部原始账本。

## 优化器验收协议

优化器按风险、换手、收益参数族研究，以收益、回撤与交易次数构造 Pareto 前沿，近似收益档优先低回撤与少交易。普通及压力 holdout 是推广门：财富至少保留基线 99%，回撤最多恶化 0.5 个百分点，交易最多增加 3%；只有财富至少提高 5% 时才允许突破交易限制。此协议不是日常买卖规则，不因发布版本而改变。

## 账户建议与治理观察

账户候选评分保留 15% 行业相对强度，比较 20／60 日细分画像均值与完整科技候选池均值。必要候选缺失、提供层标记陈旧或实际截止日不一致时，不能缩小横截面并用中性值继续推荐，而是抑制新增买入。可用持仓的成本保护、趋势退出和可卖数量提示仍独立保留。

账户快照的 `schema_version=3` 是输入数据协议，不是产品发行版本。账户、日期、金额、可卖数量、峰值和建仓证据均须真实合格。峰值证据不完整时披露 `PEAK_EVIDENCE_INCOMPLETE`，停用依赖该证据的保护；买入 `shares=0`，`indicative_target_shares` 仅为收盘估算。真实账户快照不进入历史回放，也不提供券商执行或跨日账本恢复。

治理模块读取状态形成预热健康、独立风险意见、袖套共识和覆盖置信度，不直接修改交易账本；应用层另行消费预热状态，`NOT_READY` 抑制新增买入，`DEGRADED` 本身只提示。风险事件的 1／3／5／10／20 日结果和机会成本是事后分析，禁止回填为当时输入。边界与入口见 [README](../README.md) 和[诊断说明](DECISION_DIAGNOSTICS.md)。

## 数据、因果与执行限制

前复权数据可能因公司行动重述；科技股票池有幸存者及事后关注偏差，集中上涨窗口会放大收益。收盘生成信号，模拟成交最早在下一可交易日开盘；日线无法证明盘中路径、排队、冲击和全部特殊交易规则。跳空、连续跌停及流动性不足可能使损失超过保护线。

日扫默认指数目录为独立运行目录 `data_cache/regime`，冻结输入受写保护。模拟日扫和账户建议独立检查沪深交易日日历及应覆盖日；日历仅覆盖 2024–2026 年，必要指数缺少目标交易日即失败关闭，不能用自然日容忍或 `--allow-stale` 绕过。股票缺失处理按入口区分，详见[数据说明](../data/README.md)。
