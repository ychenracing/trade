# 验证结果、证据身份与适用范围

## 如何判断一份结果能证明什么

工程回归、来源绑定的正式接受、历史对照、被拒候选和只读审计不是同一种证据。文档记录既有结果及其来源，不能仅因维护代码或修改文字，就声称旧经济结果已经在当前 HEAD 重新计算。动态分支、checks、reviews 和任务状态以实时 GitHub 及匹配 PR 为准，不复制成永久状态表。

收益率 `total_return` 与财富倍数不同：财富倍数为 `1 + total_return`；下文百分比按相应原始比例转换。最大回撤通常以负数报告，门禁使用其严重程度时可能取绝对值。`TradeRecord` 条数与日期／股票／方向桶分别统计，后者不是券商订单数，也不能证明跨袖套合单或净额。

## 优化器验收协议

优化器按风险、换手、收益三个参数族研究，使用收益、回撤与交易次数三目标 Pareto 前沿，近似收益档优先低回撤与少交易。普通及压力 holdout 是推广门：财富至少保留基线 99%，回撤最多恶化 0.5 个百分点，交易最多增加 3%；只有财富至少提高 5% 时才允许突破该交易限制。研究协议不是日常报告的买卖规则，也不因文档改动而自动触发。

## 账户建议与治理观察的验证范围

账户候选评分保留 15% 行业相对强度，使用 20／60 日收益比较细分画像均值与完整 AI 候选池均值；任一必要候选缺失、提供层标记陈旧或实际截止日不一致时，不能缩小横截面并用中性值继续推荐，而是抑制新增买入。可用持仓的成本保护、趋势退出和 T+1 卖出提示仍独立保留。

账户只接受严格 v3 同日 `AccountSnapshot`，账户与日期匹配请求。建仓早于加载窗口且没有 `highest_close` 时标记 `PEAK_EVIDENCE_INCOMPLETE` 并停用依赖完整峰值的保护。买入 `shares=0`，`indicative_target_shares` 只是收盘估算；快照不进入回放引擎，不提供券商执行或跨日账本。输入、连续性与安全排错见 [README](../README.md)。

`quantfusion.risk.governance` 读取既有状态形成观测，不直接改写模拟交易账本；独立风险意见不直接生成订单。但模拟日扫另行消费预热健康状态，`NOT_READY` 抑制新增买入，`DEGRADED` 本身只提示。历史“零行为漂移”对照只覆盖其绑定的回放输入与源码，不能据此声称应用层完全不消费治理输出。

| 治理字段 | 证明或解释范围 |
|---|---|
| `warmup_health` | 预热三级状态、可观察覆盖、新上市／陈旧与原因；模拟日扫独立消费健康门 |
| `risk_opinion` | 当日独立环境意见、等级、置信度、建议敞口与原因，不是订单 |
| `sleeve_agreement` | 袖套共识、部署率、最弱袖套与退化计数，不自动成为买卖信号 |
| `risk_governance_series` | 逐日观察序列，不改写过去决策 |
| `risk_event_calibration` | 1／3／5／10／20 日事后窗口、警报精确度／召回、误报与机会成本，不回填为当时输入 |

正式压力晋级另有相对可比基线的财富、回撤分位、最差结果、成交桶、风险减仓和排列约束。相对门与应用层健康失败关闭分别承担职责，不能混写为“治理字段不进入任何路径”或“所有观察指标都会交易”。具体经济判据仍以有效合同和规范计算为准。

## 数据与执行限制

前复权历史可能因公司行动被来源重述；冻结股票池具有幸存者及事后关注偏差，科技上涨样本会放大收益。日线开盘模型不能重现盘中路径、排队、真实冲击和全部特殊交易规则。收盘风险信号与下一可交易开盘之间存在跳空、连续跌停和流动性风险，18% 验收目标不是实盘亏损保证。

历史被拒随机子集的 -12.1056% 收益、-21.2231% 回撤只属于上文指定候选，不能当作现行正式分布。默认开启预算的弱市机会成本、正式接受的有限例外，以及真实账户不能自动恢复完整历史风险状态等限制分别保留，不用某个高收益窗口掩盖。

当前日扫指数默认目录为独立运行目录 `data_cache/regime`；显式指定冻结目录只会读取既有输入，不代表请求日数据已更新。模拟日扫和账户建议入口独立校验有限交易日日历及请求应覆盖的交易日；任一必要指数缺少该交易日记录时失败关闭，即使两个指数仍在旧自然日容忍范围内也不能继续。股票缺失后的处理仍按入口区分，实际输入要求与使用限制见 [data/README.md](../data/README.md)。
